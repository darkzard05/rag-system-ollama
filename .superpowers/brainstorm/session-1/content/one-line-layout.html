한 줄 배치 + OLLAMA 통합 예제

RAG와 SYSTEM을 한 줄에 두되 색상으로 구분하고, 그 아래 OLLAMA를 배치한 4가지 스타일입니다.

1. Classic Split (신뢰/안정)
🤖
RAG SYSTEM
OLLAMA ENGINE

평가: 가장 정석적인 레이아웃. RAG가 강조되면서도 SYSTEM이 색상으로 명확히 분리되어 읽기 쉽습니다.

2. Cyber Glow (미래지향/강렬)
⚡
RAG SYSTEM
OLLAMA

평가: 색상 대비가 가장 강렬합니다. OLLAMA를 이탤릭체와 넓은 자간으로 배치하여 '엔진'의 속도감을 표현했습니다.

3. Minimalist Mono (세련/깔끔)
🧠
RAG system
powered by ollama

평가: 폰트 두께와 대소문자 차이를 이용한 절제된 스타일. SYSTEM을 소문자로 두어 RAG를 더욱 돋보이게 합니다.

4. Bold Energy (열정/혁신)
🔥
RAG SYSTEM
ollama_core

평가: 붉은 계열의 포인트 컬러를 사용. OLLAMA를 언더바(_) 형식의 코드 스타일로 표기하여 개발자 친화적인 느낌을 줍니다.
