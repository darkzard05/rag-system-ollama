확장 버튼 소멸 원인 파악 (Streamlit 1.54.0 대응)

기술적 분석 결과: 버튼이 가려진 것이 아니라 '삭제(Hide)'된 상태입니다.

발견된 치명적 오류

/* ui.py L141-L144 */
[data-testid="stSidebarCollapseButton"],
[data-testid="stToolbar"],
[data-testid="stDecoration"] {
  display: none !important;
}

최신 Streamlit(1.54.0)에서는 사이드바를 여는 버튼과 닫는 버튼 모두 stSidebarCollapseButton이라는 ID를 공유합니다. 따라서 위 코드가 확장 버튼까지 완전히 제거해버린 것이 원인입니다.

수정 전 (현재 상황)
🚫
버튼이 CSS에 의해 제거됨
(display: none)
수정 후 (해결 방안)
>
사이드바 내부 버튼만 선택적으로 숨기고,
외부 확장 버튼은 스타일을 입혀 노출합니다.

최종 개선 계획

  • CSS 수정: [data-testid="stSidebar"] [data-testid="stSidebarCollapseButton"] 처럼 범위를 한정하여 사이드바 내부의 '닫기' 버튼만 숨깁니다.
  • ID 대응: stSidebarCollapseButton을 새로운 확장 버튼 셀렉터로 등록합니다.
  • 레이아웃 여백: 앞서 제안한 대로 버튼 위치를 (15px, 15px)로 옮기고 PDF 뷰어에 좌측 여백을 추가하여 겹침을 방지합니다.
