# PDF 하단 네비게이션 UI 개선 설계 사양서 (v1.0)

- **작성일:** 2026-06-11
- **목표:** 네비게이션 이동을 통한 시각적 균형 확보 및 페이지 표시 레이아웃 자연스럽게 개선

## 1. 개요
현재 PDF 뷰어 상단에 위치한 페이지 조작 바를 하단으로 이동시키고, 우측 채팅 입력창과 수평적 대칭을 이루도록 배치합니다. 또한, 기존의 분절된 `1 / 20` 표시 형식을 일체형 'Page X of Y' 스타일로 변경합니다.

## 2. 주요 변경 사항

### 2.1 위치 이동 (Navigation Repositioning)
- **대상:** `src/ui/components/viewer.py`
- **변경:** PDF 본문 컨테이너(`st.container`) 위에서 호출되던 `_display_pdf_controls()`를 컨테이너 아래로 이동.

### 2.2 레이아웃 및 디자인 개선 (Visual Polish)
- **표시 형식:** `[이전]  Page [ 1 ] of 20  [다음]`
- **기술적 변경:** 
    - 4컬럼(`[1, 1.2, 0.8, 1]`) 구조를 3컬럼(`[1, 2, 1]`)으로 단순화.
    - 중앙 컬럼 내에서 `Page`, `[숫자]`, `of`, `전체페이지`를 한 줄에 밀착 배치.
    - `st.number_input`의 레이아웃 오버헤드를 줄이기 위해 커스텀 CSS 적용 고려.

### 2.3 전체 레이아웃 높이 조정 (CSS Fix)
- **대상:** `src/ui/ui.py`
- **내용:** 네비게이션이 하단으로 내려감에 따라 본문 영역이 상단 여백 없이 시작하도록 `calc` 공식 업데이트.

## 3. 예상 효과
- **UX 일관성:** 좌측(문서 조작)과 우측(질의 입력)이 모두 하단 조작계로 통일됨.
- **가독성:** 페이지 정보가 분절되지 않고 하나의 문장처럼 읽힘.
