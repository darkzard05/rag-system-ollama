현행 레이아웃 분석: 고정 1:1 비율

PDF Viewer
Chat Interface

진단: 현재 st.columns([1, 1]) 방식으로 구현된 레이아웃은 다음과 같은 UX 저하를 유발합니다.

  • 🚨
    정보 밀도 불균형
    PDF의 세밀한 도표를 볼 때는 넓은 화면이 필요하지만, 채팅 답변이 짧을 때는 우측 공간이 낭비됩니다.
  • 🚨
    컨텍스트 전환 피로도
    사용자의 시선이 좌우로 과도하게 분산되어, 긴 문서를 읽으며 동시에 대화하는 '멀티태스킹' 효율이 떨어집니다.
  • 🚨
    반응형 대응 한계
    노트북 등 작은 화면에서 2컬럼 고정 시, PDF 텍스트가 너무 작게 렌더링되어 가독성이 심각하게 훼손됩니다.

개선 제안: 유동적 공간 관리 (Adaptive Workspace)

단순한 고정 배치를 넘어, 사용자의 의도(Intent)에 반응하는 레이아웃으로 진화해야 합니다.

  • 가변형 분할 (Resizable Splitter): 사용자가 마우스 드래그로 직접 영역 비율을 조정 (Streamlit 기본 기능 한계 극복 필요)
  • 포커스 모드 (Focus Mode): PDF만 보기 / 채팅만 보기 버튼을 통해 특정 영역을 일시적으로 전체 화면화
  • 지능형 자동 조절: 문서 분석 중에는 PDF 강조, 답변 생성 중에는 채팅 영역 확대
